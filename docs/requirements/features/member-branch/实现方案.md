| `src/shared/protocol.ts` | `ws.branch.create`、`ws.branch.refs`、`member.commit`，`ws.switch` 可带 `member` |
| `src/main/operations.ts` | 转发 |
| `src/renderer/src/stores/workspace.ts` | 编排，不拼 git |
| `src/renderer/src/pages/WorkspacePage.vue` | 组合根：成员行「分支」 |
| `crates/core/tests/member_branch.rs` | 单成员与主仓隔离 |

不带 `--member` 的创建和切换仍作用于每个成员。
