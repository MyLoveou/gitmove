# 决策记忆

## 2026-11-07 · 桌面端以修订刻度为第一屏

- **决定**：总览和工作区的第一屏是当前工作区的修订读数。成员对齐是唯一主操作（先更新 pin，再按 lock 检出）。里程碑代号和渐变标志撤出界面。
- **为何**：七个导航和同权重按钮让「拉取规范库」没有一条路径。
- **不选**：不换色板、不换字族、不给每个页面单独做皮肤。

## 2026-11-07 · 成员分支单独记一笔，本轮不实现

- **决定**：单成员的新建分支、切换、提交记在 `docs/requirements/features/member-branch/`。现有「全员切到同名分支」保留。
- **为何**：用户要在一个成员上开分支并提交，今天的切换会带动每个成员。
- **不选**：不在这一轮改 Rust 核心或协议。

## 2026-11-07 · 操作反馈改成短时浮层，主色改成修订印

- **决定**：点按钮后的成功和失败不再占页面横幅，改成右下角可关掉的短时浮层。状态本身（没选项目、没声明工作区、缺核心）仍留在页面上。按钮间距从 8px 提到 16px。底色改成墨色，主按钮用实心琥珀色，字是深色。
- **为何**：横幅会一直留在页面上；青绿半透明主按钮和 8px 间距让「日志、钩子和运行时」挤成一团。
- **不选**：不加组件库，不换字体。概念未另派独立生成，只留这一个方向。
